# Шаг 5: проведение анализов

Выполни анализы из плана работ, проверь гипотезы и собери базу доказательств. На этом шаге больше всего обмена с пользователем — он валидирует допущения перед каждым анализом и проверяет результаты по мере появления.

## Фаза INPUT (на анализ или пакет)

1. «Ключевые допущения: мне нужно принять [X], [Y], [Z]. Разумно? Есть ли цифры лучше?»
2. «Диапазоны чувствительности: [низкий/базовый/высокий]. Согласуется?»
3. «Пробел в данных: у меня нет [X]. Использовать [прокси] или ты можешь предоставить?»
4. «Методология: я подойду через [метод]. Есть замечания?»

Не запускай анализ, если пользователь отметил допущение как неразумное.

## Артефакты

1. **Аналитический воркбук** (.xlsx): сводный лист (одна строка на анализ: имя, вывод, импликация) + по листу на анализ + лист допущений
2. **Документ выводов** (.md): нарративная сводка по шаблону ниже

## Исполнение по каждому анализу

1. Сформулируй вопрос, 2. Выполни анализ, 3. Примени тест «и что?», 4. Оцени гипотезу (подтверждена / частично / опровергнута), 5. Зафиксируй уточняющие вопросы.

### Работа с данными

**С данными пользователя**: используй xlsx-скил, собери чистый воркбук, документируй допущения и преобразования.
**Без данных**: НЕ оценивай молча. По каждому допущению предложи значение с обоснованием. Дай диапазоны чувствительности. Цитируй публичные источники. Спроси, есть ли у пользователя лучшие внутренние данные.

**Учёт источников (обязательно)**: для каждой точки данных, использованной в анализе, фиксируй источник (например, «Годовой отчёт компании, FY2024», «Bureau of Labor Statistics», «Росстат», «Оценка менеджмента», «Анализ команды»). В колонке `sources` на листе допущений в воркбуке. Эти источники протянутся через шаги 6–8 и попадут на каждую страницу/слайд финального артефакта, где есть цифры.

### Качество и согласованность данных

Куратируй данные жёстко — до шага 8 доходят только цифры, заслужившие место.

- **Свежесть**: фиксируй год. Для быстрых доменов (AI, крипта, биотех) данные старше 18 месяцев под подозрением. Помечай или выбрасывай устаревшее.
- **Перекрёстная проверка**: сравнивай все цифры, которые соседствуют в артефакте. Если они дают противоречивые истории (например, дико разные TAM для похожих отраслей) — разбирайся, согласовывай или выбрасывай. Несовместимые расхождения показывай пользователю.
- **Меньше — лучше**: две прочные перекрёстно проверенные точки лучше десяти, надёрганных из разных отчётов.
- **Сначала инсайт**: открывай вывод стратегической импликацией, а не цифрой. Перепиши «TAM = $4.2B» как «Рынок достаточно велик, чтобы поддержать нескольких игроков — оценочно ~$4 млрд».

### Гайды по выполнению анализа

**Тренд**: график во времени, CAGR, точки перегиба. И что: ускоряется, замедляется или стабильно?
**Сегментация**: разбивка по измерениям, аутлаеры, доля от целого. И что: где концентрация / дисперсия?
**Бенчмаркинг**: сравнение с пирами, нормализация по масштабу, размер разрыва. И что: насколько велик разрыв, сужается или расширяется?
**Финансовое моделирование**: входы → расчёты → выходы, базовый кейс + чувствительность, ключевые метрики (NPV/IRR/срок окупаемости). И что: держится ли экономический кейс?
**Поиск первопричин (root cause)**: углубляйся в ветки с данными, квантифицируй вклад каждой ветки, выяви топ-2–3 драйвера.

## Фаза REVIEW

Показывай выводы по мере появления. Сверяй с опытом пользователя, обсуждай статус гипотез, помечай неожиданные паттерны, валидируй интерпретации.

**Обработка правок**: пользователь может оспорить допущения (→ переделай и пересчитай), оспорить вывод (→ разберись с расхождением), запросить более глубокий анализ, дать новые данные или попросить разворот направления. На любую правку, меняющую вывод, покажи обновлённый результат на утверждение.

**Останавливайся и сверяйся**: после каждой пачки P1, когда выводы существенно противоречат гипотезам, при оценочных решениях, при тяжёлых допущениях, перед сменой направления.

**Не переходи к шагу 6, пока все ключевые выводы не проверены и не утверждены.**

## Ловушки

- **Анализ без «и что?»**: график без инсайта — украшение
- **Ложная точность**: округляй разумно
- **Подтверждающее искажение**: если анализ опровергает твою гипотезу, это ценно — не прячь
- **Молчащие допущения**: никогда не оценивай без вопроса пользователю
- **Не показал обновление после правки**: всегда показывай обновлённую версию

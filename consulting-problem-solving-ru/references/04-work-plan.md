# Шаг 4: построение плана работ

Переведи приоритеты в конкретные анализы с понятными выходами. Это определяет, что делается, какие данные нужны и в каком порядке.

## Фаза INPUT

1. «Какие данные у тебя есть под рукой?» — Критично; план без данных бесполезен.
2. «Есть ли конкретные анализы, которые твои стейкхолдеры ожидают увидеть?»
3. «Есть ли сроковые ограничения или промежуточные вехи?»
4. «Предпочтения по подходу для ключевых анализов?»
5. «Какой подход к оценке приемлем там, где данных нет?» — Консервативный или агрессивный.

## Артефакт: таблица плана работ (.xlsx)

Используй xlsx-скил. Структура:

**Лист 1 — Summary**: название проекта, ключевой вопрос, дата, обзор воркстримов (название, число анализов, усилия, веха), таймлайн, если задан.

**Лист 2 — Detailed Analysis Plan**: колонки: ID (формат WS1-A1), Workstream, Analysis Name, Question to Answer, Approach, Data Needed, Data Source, Data Status (Available / Needed / Gap), Output Format, Hypothesis, Priority, Dependencies, Status.

**Лист 3 — Data Inventory** (когда применимо): Data Item, Source, Status (Have / Need / Unavailable), Format, Notes, Workaround if unavailable.

### Определение анализа

Каждый анализ отвечает на один конкретный вопрос. Опиши: воркстрим, имя анализа, вопрос, подход, нужные данные, источник, выход, гипотезу, приоритет.

### Секвенирование

Картируй зависимости: **Independent** (параллельно), **Dependent** (нужен прежний выход), **Gating** (должен завершиться до решения о следующих шагах).

### Типовые виды анализа

**Количественные**: тренд, сегментация, бенчмаркинг, чувствительность, финансовое моделирование, регрессия / корреляция.
**Качественные**: ревью best practice, картирование процесса, анализ стейкхолдеров, оценка рисков.


## Фаза REVIEW

Валидируй список анализов, подтверди статус данных, обсуди выбор подходов, подтверди секвенирование, валидируй подход к допущениям. **Не переходи к шагу 5 без явного утверждения.**

## Ловушки

- **Слишком расплывчато**: «Проанализировать рынок» — это не анализ; уточни вопрос, данные и метод
- **Нет плана по данным**: каждый анализ должен иметь источник данных
- **Нет секвенирования**: картируй зависимости, чтобы избежать переделки
- **Сверхпланирование**: 15–25 анализов — норма; >30 — приоритизация недостаточна
- **Допущения о данных**: всегда сверяйся с пользователем
